| دسته | تعداد | مثال | وضعیت |

| **یکتای زیپ (فقط روی گوشی)** | ~70% | `0.rar` لاگ مرورگر, `01.zip` گزارش پاکسازی, `02.zip` Screenrecorder, `All.zip` Tttsm | **نگه دار - روی درایو نیست** |

## دستور ترموکس برای مقایسه عمیق (هش واقعی)

```bash
# 1. لیست درایو (از متادیتا که دارید) vs لیست گوشی
ls -R /sdcard/FarsiVoiceAI* > /tmp/phone_list.txt
# (درایو لیست رو از CSV دارید: FVA_relevance_map.csv)

# 2. هش برای همپوشانی مشکوک (کتاب 56M):
sha256sum "/sdcard/0.rar" | cut -d' ' -f1
# vs MD5 درایو: dcaae964... (کتاب) - اگر هش یکی شد تکراری مطمئن

# 3. مدل 63M فقط روی درایو - چک کنید روی گوشی نیست:
find /sdcard -name "*.onnx" -exec ls -lh {} \;

# 4. کد 24M فقط روی درایو:
find /sdcard -name "*FarsiVoiceAI_code*" -exec ls -lh {} \;
```

منتظر تایید برای مرحله یکتاسازی نهایی.
