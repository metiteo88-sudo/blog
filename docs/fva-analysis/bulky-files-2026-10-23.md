## محدودیت صادقانه این آنالیز

**این آنالیز حجیم‌ها فقط از روی نام و حجم است، نه محتوا:**
- داخل `03.zip` و `0.rar` واقعاً چی هست - نمی‌دونیم (متادیتا)
- آیا `fa_IR-gyro-medium.onnx` واقعاً مدل درست هست - بدون باز کردن فایل نمی‌شه گفت
- تکراری‌ها فقط با MD5 گزارش شدن، ولی بدون SHA-256 جریانی (چون بایت نداریم) اطمینان کمتره
- برای اطمینان «بالا» و بخش «الف) مرتبط قطعی» باید کپی محلی داشته باشیم تا متن تا انتها خوانده بشه

**برای آنالیز عمیق حجیم‌ها باید:**
```bash
# اگر کپی محلی داشته باشیم:
python3 fva_analyze.py "/My Drive/0.rar" --out /tmp/huge_report
# یا حداقل پوشه حاوی این 3 فایل:
python3 fva_analyze.py "/My Drive" --out /tmp/huge_report --expected-files 216
```
اون موقع می‌گیریم: `archive_contents.csv` با لیست داخلی zip/rar + `duplicate_candidates.csv` با SHA-256 واقعی + بخش الف با اطمینان بالا.
